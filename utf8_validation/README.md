# UTF-8 VALIDATION

## Purpose
Determines if a specified list of numbers forms a valid UTF-8 data

- Method Type: **`Iterative`**
- Modules: **None**

holbie@VM-Algos:~/utf8_validation$ ./0-main.py

holbie@VM-Algos:~/utf8_validation$
